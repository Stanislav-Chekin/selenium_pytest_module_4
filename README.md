# Selenium + Pytest Automation Project (QA.GURU Module 4)

Учебный проект по автоматизации тестирования UI на Python с использованием Selenium и Pytest. 
В рамках домашнего задания проект трансформирован с применением паттерна **Page Object Model (POM)** и продвинутых возможностей PyTest.

## 🛠 Технологии и инструменты
*   **Язык:** Python 3.x
*   **Инструмент автоматизации:** Selenium WebDriver
*   **Тестовый фреймворк:** Pytest
*   **Паттерн проектирования:** Page Object Model (POM)

## 📂 Структура проекта
*   `selenium_tests/` — корневая папка тестов
    *   `pages/` — Page Object классы (описание страниц и локаторов)
    *   `tests/` — Тестовые сценарии
    *   `conftest.py` — Фикстуры и хуки PyTest
*   `lesson_materials/` — Учебные примеры от преподавателя
*   `pytest.ini` — Конфигурационный файл Pytest (маркеры, пути, настройки)

## 🚀 Реализованные возможности PyTest (в рамках ДЗ)
В проекте сознательно применен максимум изученных возможностей PyTest:
1.  **Фикстуры (conftest.py):** Управление драйвером (`scope="function"`, `yield` для гарантированного закрытия браузера).
2.  **Фикстура Page Object:** Передача готовой страницы в тест для чистоты кода.
3.  **Параметризация (`@pytest.mark.parametrize`):** Прогон тестов с разными наборами данных (DDT).
4.  **Data Classes (`@dataclass`):** Хранение тестовых данных в виде объектов для наглядности.
5.  **Маркеры (`@pytest.mark.smoke`, `@pytest.mark.regression`):** Разделение тестов на быстрые и полные наборы.
6.  **Ожидаемые падения (`@pytest.mark.xfail`):** Обработка известных багов браузера (например, валидация email).
7.  **Пропуск тестов (`@pytest.mark.skip`):** Отключение неготовых тестов.
8.  **Кастомный хук (`pytest_runtest_makereport`):** Автоматическое создание скриншотов при падении тестов (сохраняются в папку `screenshots/`).
